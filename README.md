# Sistema de Gestión de Ofertas (SGO) - CSIC MiNaWeb

El Sistema de Gestión de Ofertas (SGO) es una plataforma integral desarrollada para la Sala Blanca (MiNa) del Instituto de Micro y Nanotecnología (IMN-CNM) perteneciente al CSIC. 

Su propósito principal es digitalizar y unificar el flujo de trabajo entre investigadores, técnicos y la administración, optimizando la solicitud de servicios, el control presupuestario y la facturación de los trabajos realizados en las instalaciones.

## Características Principales

*   **Gestión de Catálogo Centralizada:** Administración de servicios técnicos y tarifas diferenciadas (Interno, CSIC, Público, Privado).
*   **Sistema de Roles y Accesos (RBAC):** Interfaces personalizadas para Administradores, Técnicos y Clientes (Investigadores).
*   **Trazabilidad de Ofertas:** Ciclo de vida completo de una petición (Solicitada → Presupuestada → Aceptada → Facturada → Finalizada).
*   **Facturación Agrupada:** Generación automática de cargos a los Investigadores Principales (IP) o cuentas internas de proyectos.

## Tecnologías Utilizadas

*   **Backend:** Python (FastAPI)
*   **Base de Datos:** PostgreSQL
*   **Frontend:** Vanilla JavaScript, HTML5, CSS3
*   **Despliegue:** Docker, Docker Compose
